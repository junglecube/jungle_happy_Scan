# V3.10.0 配置与升级说明

V3.10 修复两个响应上下文的检测盲区。XXE 现在会从 `application/x-www-form-urlencoded` 的键值中提取 XML 参数，即使整个请求不是 XML Content-Type，也会对 XML、CDATA 和多字段表单建立嵌套插入点。XSS 会递归检查 HTML/XML 包装节点中的 JSON 字符串，并结合属性上下文、隐藏元素和 CSP 头判断回显是否具有浏览器可执行性，降低漏报和不可执行回显的误报。

V3.10 保持配置向后兼容。只替换可执行文件并重启即可沿用原 config；原有业务成功/失败关键词和插件规则会继续生效。
