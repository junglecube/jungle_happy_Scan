jungle_happy_Scan V2.4 单接口同步扫描 MCP Tool 标准
======================================================

文档版本：2.1
底层 HTTP：POST http://<scanner-host>:8888/api/v2/jungle_happy_scan
Lite HTTP：POST http://<scanner-host>:8888/api/v2/jungle_happy_scan_lite
适用范围：仅限已授权测试环境；调用会发送真实漏洞检测 Payload。

二、tools/call
------------

请求：

{
  "jsonrpc":"2.0",
  "id":3,
  "method":"tools/call",
  "params":{
    "name":"jungle_happy_scan",
    "arguments":{
      "http":"GET /api/user?id=1 HTTP/1.1\r\nHost: test.example.local\r\n\r\n"
    }
  }
}

Adapter 应将 arguments 原样 POST 到 V2 HTTP 接口，HTTP 读取超时建议不少于 600 秒；把 HTTP JSON 同时放入 structuredContent，并在 content 返回同一 JSON 文本。HTTP 200 仍可能包含 scan.status=failed，调用方必须检查 status 与 coverage.complete。

Lite Tool 可命名 jungle_happy_scan_lite，入参 Schema 相同，底层改为 /api/v2/jungle_happy_scan_lite；其 evidence 不包含完整 request/response。
